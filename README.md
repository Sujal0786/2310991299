# Notification System

This repository contains a full-stack notification system assignment solution.

## Folders

- `notification_app_be` - Node.js/Express backend with logging middleware, REST APIs, MongoDB model, and Socket.io real-time notification support.
- `notification_app_fe` - React frontend for viewing notifications.
- `notification_systemdesign.md` - System design response for Stage 1 to Stage 6.

## Quick Start

### Backend
```bash
cd notification_app_be
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd notification_app_fe
npm install
npm run dev
```
